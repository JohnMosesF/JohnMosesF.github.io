Enterprise Branch Network Design & Troubleshooting

An internship project completed at Besant Technologies, focused on designing a branch network, configuring VLANs and routing, simulating failures, and restoring connectivity through structured troubleshooting.

Role

Network Support Intern

Organization

Besant Technologies

Focus

Troubleshooting

Objective

The objective was to build a realistic enterprise branch network in a lab environment and validate that users across VLANs could communicate securely and reliably through proper routing and addressing.

Work Completed

  • Designed an enterprise branch network topology with a structured IP addressing plan.
  • Configured VLAN segmentation to separate network traffic by function.
  • Implemented inter-VLAN routing so required services could communicate across segments.
  • Configured routers and switches inside Cisco Packet Tracer.
  • Simulated network failures, misconfigurations, and connectivity issues.
  • Used OSI layer-based troubleshooting to identify the root cause and restore network connectivity.

Troubleshooting Approach

Layer 1 and Layer 2

I checked physical/link status, switchport assignments, VLAN membership, and trunk behavior to make sure traffic could move inside the correct broadcast domains.

Layer 3

I verified IP addressing, subnet masks, default gateways, and routing behavior to confirm that inter-VLAN traffic was moving through the expected router paths.

Service Resolution

I validated DNS-related behavior and basic reachability checks so the network could support realistic user and service communication.

Outcome

The final lab network restored connectivity after simulated failures and showed a practical understanding of IP planning, VLAN design, routing, and structured root-cause analysis. This project supports my readiness for entry-level Network Support and Cloud Support responsibilities.
